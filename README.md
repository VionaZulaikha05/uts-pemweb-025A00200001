## 2. Deskripsi Singkat Tema
Proyek ini adalah website profil dan katalog dinamsi untuk Kantin Wareg. Data disimpan dalam bentuk array multidimensi pada file 'data.php' (belum menggunakan database). Tampilan dibuat menggunakan HTML semantik dan CSS murni.

## 3. Cara Menjalankan di Localhost
1. Pastikan aplikasi Laragon sudah terinstall dan berjalan.
2. Karena keterbatasan pada folder 'www' bawaan, proyek ini diletakkan di direktori root lain (F:/cod/smt 3/WEB).
3. Menggunakan fitur **Root** agar Laragon mengenali folder proyek tersebut.
4. Seetelah server (Apache/PHP) berjalan, akses halaman profil melalui URL yang tertera di Laragon.
5. Halaman katalog dapat doalses dengan mengklik menu navigasi atau membuka 'katalog.php'.
